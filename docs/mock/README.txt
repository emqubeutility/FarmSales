Farm Sales and Inventory: MVP mock (standalone HTML)

Open index.html in any browser (double-click works, no server needed).
The sidebar links every screen. Files:
  dashboard.html, pos.html, orders.html, returns.html,
  items.html, receive-stock.html, packing.html, batches.html, labels.html,
  b2b.html, reports.html, settings.html, delivery.html

pos.html is interactive (scan item+batch labels such as RF500-260920A, or type; stock goes out first expiry first; discounts, payment, receipt).
All other screens are static layouts with sample data.
Placeholders in [SQUARE BRACKETS] are for your details (brand, GSTIN, FSSAI, UPI ID, HSN, GST rates, pincodes).
Fonts load from Google Fonts when online; the pages fall back to system fonts offline.
